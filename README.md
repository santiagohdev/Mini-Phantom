# 👻 Mini Phantom

A simple clone inspired by the look and feel of the Phantom website.

## 🧠 About

This is a basic frontend project built to practice layout, styling, and UI replication using only HTML and CSS.

The goal was to recreate a clean and modern design similar to the Phantom website, focusing on structure and visual details.

## 🛠️ Technologies

- HTML5  
- CSS3  

## 🎯 Features

- Clean UI inspired by Phantom  
- Responsive layout
- Structured and organized code  

## 📚 What I Learned

- Better understanding of layout and positioning  
- Improving CSS styling and structure  
- Replicating real-world designs
